# Evaluation: rule classifier vs trained gradient-boosted model

_Generated by `industrial-data/scripts/train_classifier.py` (seed 0)._

**Verdict:** The trained model BEATS the rule classifier on macro-F1: macro-F1 rules 0.656, model 0.870, model with thermal-only features 0.338. Accuracy 0.607 / 0.877 / 0.444.

> **These labels are weak, rule-derived and NOT ground truth.** Facility proximity (OSM) and land cover (ESA WorldCover) both define the labels and are inputs to both classifiers, so the numbers measure agreement with the labelling rules on unseen regions and months, not real-world accuracy. The thermal-only model shows how much separation comes from satellite behaviour alone.

## Data
* VIIRS S-NPP archive `2025-07-01` to `2026-10-08` (562,019 detections inside India), 12,567 merged facilities (OSM + WRI GPPD; data/facilities), ESA WorldCover 2021.
* Unit: 7-day window source (same features as the live pipeline). Labels: long-run behaviour of the ~2 km cell (rules in the script header).
* Split: train = states outside the held-out set AND windows ending before 2026-04-01; test = held-out states (Andhra Pradesh, Bihār, Goa, Himāchal Pradesh, Karnātaka, Madhya Pradesh, Meghālaya, Odisha, Rājasthān, Tripura, West Bengal) AND windows from 2026-04-01. No cell appears on both sides.
* Per-class cap 1,500 cells. `other` is not a labelled class; the rules may predict it (counted as wrong).

## Limitations
* Weak labels, single archive (S-NPP only, ~15 months), one train/test split; no confidence intervals.
* `industrial_fire_candidate` here means *episodic detection at a facility*, not a confirmed fire. Real incident evidence is in `data/incidents/incident_firms_match.csv`, not in this table.
* The model cannot use month/season (held out by design); the rules do, which favours them on agriculture.
* Region and period hold-out make the test small for some classes; read support before trusting a score.
